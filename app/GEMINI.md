# Backend Application (`/app`)

This directory contains the core backend logic for the application, written in Python.

## Subdirectories

- **`/core`**: Core application components like configuration, database connections, and exception handling.
- **`/models`**: Data models and schemas.
- **`/services`**: Business logic and services that power the application's features.

## Key Files

- **`core/config.py`**: Manages application configuration.
- **`core/database.py`**: Handles database connections and sessions.
- **`services/ai_service.py`**: Contains logic for interacting with AI models.
- **`services/code_generation.py`**: Handles the generation of code based on user inputs.
