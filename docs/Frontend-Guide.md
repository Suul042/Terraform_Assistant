# Frontend Guide

This guide explains how to set up and run the Next.js frontend.

## Prerequisites

- Node.js 16 or later
- npm or yarn

## Setup

1.  **Navigate to the frontend directory**:

    ```bash
    cd frontend
    ```

2.  **Install dependencies**:

    ```bash
    npm install
    ```

    or

    ```bash
    yarn install
    ```

## Running the Application

```bash
npm run dev
```

or

```bash
yarn dev
```

The application will be available at `http://localhost:3000`.
