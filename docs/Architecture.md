# Architecture

This document provides a high-level overview of the project's architecture.

## Components

The application is composed of two main components:

- **Backend**: A Python application built with FastAPI that provides a RESTful API.
- **Frontend**: A single-page application built with Next.js and React.

## Technology Stack

- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: TypeScript, Next.js, React, Tailwind CSS
- **Database**: PostgreSQL
- **CI/CD**: GitHub Actions
