# Testing

This document describes how to run the project's tests.

## Backend Tests

To run the backend tests, navigate to the root directory and run the following command:

```bash
pytest
```

## Frontend Tests

To run the frontend tests, navigate to the `frontend` directory and run the following command:

```bash
npm run test
```

or

```bash
yarn test
```
