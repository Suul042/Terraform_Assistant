# Frontend Application (`/frontend`)

This directory contains the frontend application, built with Next.js and TypeScript.

## Subdirectories

- **`/components`**: Reusable React components.
- **`/lib`**: Utility functions and libraries.
- **`/store`**: State management for the application.

## Key Files

- **`next.config.js`**: Configuration for the Next.js framework.
- **`package.json`**: Project dependencies and scripts.
- **`tailwind.config.js`**: Configuration for the Tailwind CSS framework.
- **`src/components/ParameterForm.tsx`**: A key component for user input.
- **`src/store/app.ts`**: The main state management file.
